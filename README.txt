STALZONE Трекер 2.6 — ищет на аукционе лоты дешевле рынка и считает прибыль перепродажи.
Сам ничего не покупает.

КАК ПОЛУЧИТЬ
  Скачай STALZONE-Tracker.exe из последнего выпуска:
  https://github.com/Enotsbeye/stalzone-tracker-releases/releases/latest
  Дальше программа обновляется сама: при запуске проверяет новые версии,
  на главной появляется кнопка «Обновить». Данные при обновлении не теряются.

ДОСТУП
  Программа работает только по коду доступа. Друг запускает её, копирует
  ID своего компьютера и отправляет владельцу. Владелец в разделе «Доступ»
  вписывает имя, ID и срок и присылает код. Код работает только на том ПК.

ДРУГУ ПРИ ПЕРВОМ ЗАПУСКЕ
  - Windows может показать «Система Windows защитила ваш компьютер»:
    «Подробнее» -> «Выполнить в любом случае». Программа не подписана, поэтому так.
  - Нужны свои ключи API: написать /newapp боту @stalzone_api_bot в Telegram,
    после одобрения вставить Client ID и Client Secret в «Настройки».
  - Пока ключей нет, можно включить «Демо-режим» — там тестовые данные.

ГДЕ ДАННЫЕ
  Ключи, настройки, найденные лоты, журнал и база сделок (market.db) хранятся
  отдельно от программы: %APPDATA%\STALZONE Tracker
  Обновление, перенос или удаление .exe их не стирает. В .exe они не попадают.
  Ключи — как пароль: не отправляй никому этот файл и папку.

БАЗА СДЕЛОК
  Трекер копит сделки у тебя на ПК (по умолчанию 14 дней, меняется в «Настройках»).
  Чем дольше он работает, тем больше данных для оценки редких артефактов.
  Новые сделки докачиваются, старые не запрашиваются повторно.

СКОРОСТЬ
  Запросы к API идут параллельно, в пределах лимита EXBO (400 в минуту).
  Проверка идёт без пауз. Новые лоты API отдаёт с задержкой ~10 минут,
  быстрее этого их не увидит ни одна программа.

ПОЧЕМУ НЕТ НАХОДОК
  Смотри блок «Почти находки» под списком: там лоты дешевле рынка, которые
  не прошли твои пороги, и причина. Пороги — в «Настройках».

ПРОДАЖА
  «Мои покупки» подскажут, за сколько выставить купленное. Нажми «Выставил
  за эту цену» — трекер сообщит, если твой лот перебили, и сам закроет
  покупку, когда лот продастся.

КРАФТ
  Вкладка «Крафт»: укажи уровни навыков убежища — увидишь прибыль рецептов
  по ценам аукциона и какой навык выгоднее качать. Щёлкни рецепт — справа
  будет, за сколько выставлять готовое и почём брать каждый ингредиент.

ВИД И ЗВУК
  «Настройки» → «Вид программы»: новый (как программы Windows 11) или
  классический (как до 2.6). Там же тема. «Уведомления» → «Какой звук»:
  встроенные звуки, звуки Windows или свой файл с компьютера.

TELEGRAM
  Создай бота у @BotFather, вставь токен в «Настройки» → «Уведомления» →
  «Telegram», напиши своему боту «Start» и нажми «Найти» — Chat ID
  впишется сам. Под каждой находкой — «Купил», «Скрыть», «Тишина на час»;
  команды /status, /finds, /profit, /buys, /stop, /go, /mute, /min.
  Кнопки работают, пока трекер запущен. Бот слушается только своего чата.

РАДАР И БЫСТРАЯ ПОКУПКА
  Новый лот виден в API примерно через 10 минут, а в игре — сразу. Вкладка
  «Радар» подскажет, где дешёвые лоты бывают чаще и до какой цены их брать.
  Название находки само попадает в буфер обмена (Ctrl+V в игре), F8 копирует
  следующее, «Окно поверх игры» — для режима «в окне без рамки».

СВОИ ЦЕНЫ
  «Радар» → «Мои цены» или /target Морфин 2000 в Telegram: трекер сообщит о
  любом лоте дешевле твоей цены за штуку, даже без скидки к рынку.

ЗАПУСК ИЗ ИСХОДНИКОВ (если стоит Python)
  1. pip install requests pywebview cryptography
  2. python stalzone_app.py

СОБРАТЬ .EXE САМОМУ (обычно не нужно — .exe собирает GitHub)
  Дважды щёлкни build_exe.bat и дождись «Готово». Скрипт сам найдёт рабочий
  Python, а если его нет — поставит Python 3.12 в %LOCALAPPDATA%\STALZONE Build.
  Готовый файл — в папке dist.
