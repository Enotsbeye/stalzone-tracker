STALZONE Трекер 1.7 — ищет на аукционе лоты дешевле рынка и считает прибыль перепродажи.
Сам ничего не покупает.

КАК ПОЛУЧИТЬ
  Скачай STALZONE-Tracker.exe из последнего выпуска:
  https://github.com/Enotsbeye/stalzone-tracker/releases/latest
  Дальше программа обновляется сама: при запуске проверяет новые версии,
  на главной появляется кнопка «Обновить». Данные при обновлении не теряются.

ДРУГУ ПРИ ПЕРВОМ ЗАПУСКЕ
  - Windows может показать «Система Windows защитила ваш компьютер»:
    «Подробнее» -> «Выполнить в любом случае». Программа не подписана, поэтому так.
  - Нужны свои ключи API: написать /newapp боту @stalzone_api_bot в Telegram,
    после одобрения вставить Client ID и Client Secret в «Настройки».
  - Пока ключей нет, можно включить «Демо-режим» — там тестовые данные.

ГДЕ ДАННЫЕ
  Ключи, настройки, найденные лоты, журнал и база сделок (market.db) хранятся
  отдельно от программы: %APPDATA%\STALZONE Tracker
  Обновление, перенос или удаление .exe их не стирает. В .exe они не попадают.
  Ключи — как пароль: не отправляй никому этот файл и папку.

БАЗА СДЕЛОК
  Трекер копит сделки у тебя на ПК (по умолчанию 14 дней, меняется в «Настройках»).
  Чем дольше он работает, тем больше данных для оценки редких артефактов.
  Новые сделки докачиваются, старые не запрашиваются повторно.

СКОРОСТЬ
  Запросы к API идут параллельно, в пределах лимита EXBO (400 в минуту).
  Проверка — раз в минуту. Новые лоты API отдаёт с задержкой ~10–20 минут,
  быстрее этого их не увидит ни одна программа.

ЗАПУСК ИЗ ИСХОДНИКОВ (если стоит Python)
  1. pip install requests pywebview
  2. python stalzone_app.py

СОБРАТЬ .EXE САМОМУ (обычно не нужно — .exe собирает GitHub)
  Дважды щёлкни build_exe.bat и дождись «Готово». Скрипт сам найдёт рабочий
  Python, а если его нет — поставит Python 3.12 в %LOCALAPPDATA%\STALZONE Build.
  Готовый файл — в папке dist.
