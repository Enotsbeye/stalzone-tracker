Несколько ключей API и находки подписчикам по очереди — у каждого свои предметы.

- Ещё ключи API: «Настройки» → «Доступ к API» → «Ещё ключи», по одному в строке (Client ID, пробел, Client Secret). Запросы делятся между ключами, каждый добавляет 400 в минуту. Ключ, который EXBO не пустит, выбывает — поиск идёт на остальных.
- Подписчики выбирают предметы сами, а твой сервер проверяет и их — не только твой список.
- Каждая новая находка сначала уходит одному подписчику, которому она подходит (по его предметам и порогам), — по очереди, кто меньше получил за час. Через 2 минуты её видят все. В карточке — «🎯 только тебе», в Telegram — тоже.
- Подписчики спрашивают сервер раз в 15 секунд вместо 30.
