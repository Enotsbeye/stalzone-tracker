Исправлено то, из-за чего трекер работал плохо (нашлось по твоему журналу и базе), плюс сервер для подписчиков.

- Программа больше не «делит ключ API» сама с собой. Это была ошибка подсчёта на стыке минут: часы компьютера отставали на секунду-две, и каждую минуту проверка зря замедлялась вдвое и засоряла журнал.
- Щелчки по предметам и настройкам больше не перезапускают проверку с нуля (было до 30 перезапусков в минуту). Пороги применяются сразу, новые предметы — со следующего прохода. Перезапуск — только при смене ключей.
- Оптовые товары (Полимеры, Огромный артефактный фрагмент) считаются правильно. Ложного «формат цен понят неверно» больше нет, фрагменты снова проверяются.
- «Задержка API» показывает, через сколько новый лот виден в API (по твоей базе ~10 мин). Раньше там была завышенная медиана.
- Шанс продажи строже: меньше доверия к малому числу сделок, сильнее штраф за конкурентов и залежавшиеся лоты, потолок 90%.
- Сервер для подписчиков: твоя программа проверяет аукцион твоим ключом и раздаёт находки. Подписчику нужен только код — без ключей EXBO. «+30 дн.» продлевает, «Отключить» сразу закрывает доступ.
- Список предметов — до 300. Лишнее больше не отрезается молча.
