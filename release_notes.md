Автообновление: программа сама проверяет новые версии и ставит их в один клик.

- При запуске — проверка выпусков на GitHub, на главной кнопка «Обновить».
- .exe собирается на GitHub автоматически — build_exe.bat больше не нужен.
- Поиск: параллельные запросы, проверка раз в минуту.
- Своя база сделок, тренд цены, пометка проданных лотов.
- Исправлено: сборка на Windows падала на самопроверке из-за эмодзи в выводе.
