Доступ для всех — проще и без потери скорости: код можно просто отправить, а находки подписчикам раздаёт твой сервер.

- Код доступа без ID компьютера: впиши, кому, и срок — и отправь. Компьютер подписчика привяжется сам при первом подключении.
- Код на группу: поставь больше мест (например, 50) — один код для канала или чата, каждый новый компьютер занимает место. Если подписчик сменил компьютер, нажми «Освободить».
- Готовое сообщение подписчику: ссылка на программу, код и что сделать — одной кнопкой «Скопировать сообщение».
- «Открыть доступ из интернета» — одна кнопка вместо командной строки: трекер сам включает Tailscale Funnel и записывает адрес сервера. Если Tailscale что-то просит (установить, войти, разрешить Funnel), кнопка подскажет и даст ссылку.
- Подписчики берут находки с твоего сервера и твой лимит EXBO не тратят — твой поиск не замедляется, сколько бы их ни было. Галочки «вложить мой ключ API» больше нет.
- Если твоим ключом пользуется кто-то ещё, трекер покажет, сколько запросов в минуту уходит не тебе и чьи коды с твоим ключом, и подскажет, как вернуть скорость.
- Режим «Весь аукцион» из 2.3 убран.
