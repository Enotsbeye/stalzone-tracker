Новый вид окна — как у программ Windows 11. Прежний остаётся: «Настройки» → «Вид программы» → «Классический».

- Находки — таблицей, как в Диспетчере задач: купить, продать, шанс, прибыль. Сортировка — щелчком по заголовку. Справа — подробности выбранной находки и «Я купил». Стрелки ↑↓ листают, Ctrl+C копирует название.
- Сверху — общий итог: сколько, если купить всё, и сколько с учётом шанса продать.
- «Мои покупки»: блок «Заработано» за сегодня, 7 дней, 30 дней или всё время, график по дням, лучшая сделка, сколько денег в товаре и сколько ещё ожидается.
- «Крафт»: щёлкни рецепт — справа карточка: за сколько выставлять готовое (быстро, выгодно, дороже — с шансом и сроком), почём брать каждый ингредиент и выше какой цены крафт уходит в минус, сколько выйдет, если купить ингредиенты на аукционе прямо сейчас.
- Звук: свой для обычной и для особо редкой находки — встроенные, звуки Windows или свой файл с компьютера (wav, mp3, ogg). Громкость и «Прослушать». «Настройки» → «Уведомления».
- Настройки сохраняются сразу, без кнопки «Сохранить».
- Цвет кнопок — акцент из настроек Windows, рамка окна — в цвет темы программы.
- Вторая копия программы больше не запускается (раньше два поиска делили один ключ) — открывается окно первой.
- В свойствах файла программы теперь её название и версия.

Из 2.5 (если обновляешься с более ранней):
- Ещё ключи API: «Настройки» → «Доступ к API» → «Ключи EXBO» → «Ещё ключи», по одному в строке (Client ID, пробел, Client Secret). Каждый ключ добавляет 400 запросов в минуту.
- Подписчики выбирают предметы сами, сервер проверяет и их. Новая находка сначала уходит одному подписчику (по очереди), через 2 минуты — всем.
